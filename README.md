# GERS ID pages feedback

Bug reports and feature requests for [gers.page](https://gers.page), the unofficial page for any Overture GERS ID. The
site's code is private; this repository only holds its issues.

[Report a bug or suggest a feature](https://github.com/atiannicelli/gers-pages-feedback/issues/new/choose). Every page
on gers.page links here and fills in the page's address for you.

Wrong or missing map data comes from Overture's releases, so report it to the
[Overture Maps Foundation](https://github.com/OvertureMaps/data/issues/new/choose). If reporting is turned on, you can
also flag a wrong value on its GERS page.

gers.page is a personal project, not affiliated with or endorsed by the Overture Maps Foundation.
