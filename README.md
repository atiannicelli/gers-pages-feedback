# gers.page website feedback

Bug reports and feature requests for the [gers.page](https://gers.page) website. The site's code is private; this
repository only holds its issues.

This is for the website only: pages that don't load or display properly, broken links, and ideas for the site. It isn't
for the map data. gers.page shows Overture's data as released and can't change it, so report wrong or missing data to
the [Overture Maps Foundation](https://github.com/OvertureMaps/data/issues/new/choose).

[Open an issue](https://github.com/atiannicelli/gers-pages-feedback/issues/new/choose). Every page on gers.page links
here and fills in its address for you.

gers.page is a personal project, not affiliated with or endorsed by the Overture Maps Foundation.
